# Rights-gate coaching knowledge and preserve before upgrade

C2 admits Topic/Language Knowledge Assets only through explicit source, rights,
owner, and tenant checks, then lets minimal edits consume those assets only while
retaining current-evidence lineage and deterministic preservation limits. This
rejects the simpler shared vocabulary pool and whole-script rewrite path because
they can leak tenant content, invent authority, or replace a learner's facts and
voice, at the cost of allowing empty topic packs and no-change edit plans.
