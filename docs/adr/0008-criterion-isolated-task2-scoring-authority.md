# Isolate Task 2 criterion scoring and keep evidence authority in P2-02

P2-03 assesses TR, CC, LR, and GRA through four independent calls to one
versioned rubric-only route after an atomic shared preflight. The complete
Candidate Script is read-only semantic context, while every finding that uses
student evidence must resolve to validated, same-criterion P2-02 observation and
span identifiers. Official rubric claims are scoring authority;
`DERIVED_INTERNAL` dimensions are organization only. Code validates and
canonicalizes semantic output, derives midpoint bands, assigns finding and
artifact identities, and owns execution provenance. Incomplete runs never create
a Criterion Assessment Bundle, and neither internal workflow integration nor
this contract gate authorizes user-facing score promotion.
